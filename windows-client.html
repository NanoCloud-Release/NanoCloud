六个检查点

客户端问题

从安装、配置到系统网络逐层确认。每次只改一个变量，保留错误原文和发生步骤。

01

Windows SmartScreen

确认下载来源和文件完整性。只对可信安装包继续操作，不要为了启动未知文件关闭系统保护。

02

初始化失败

彻底退出旧客户端，卸载旧版并重启 Windows，确认系统时间正确后再从控制台入口安装。

03

String 索引错误

这可能来自旧版客户端与返回配置格式不兼容，也可能与 TLS 信任链有关。先清理旧配置并使用控制台推荐版本。

04

vcruntime140.dll 缺失

按客户端发行说明补齐对应的 Microsoft Visual C++ 运行库，再重启客户端。不要从不明网站下载单个 DLL。

05

浏览器可用，其他应用不可用

检查系统代理、TUN/虚拟网卡、DNS 接管和权限是否生效。应用可能没有走浏览器的代理设置。

06

断开后仍然直连

检查规则是否自动回落到 DIRECT。需要隐私保护时启用严格路由或 fail-closed，并用测试网站确认出口行为。

证书边界

https_windows.crt 证书

这是 Windows 客户端可能需要安装的公开信任链证书。公开根证书不等于抓包证书，也不意味着客户端会收集或上传你的私钥。

安装后仍报错：记录 Windows 版本、客户端版本、错误原文和发生步骤，再做网络交叉测试。

安装前

安装前检查

  • 01
    只保留一个客户端实例

    关闭旧进程和残留系统代理，避免多个工具同时接管网络。

  • 02
    重新复制订阅

    从控制台复制最新订阅，不在公开反馈中粘贴订阅、UUID、token 或私钥。

  • 03
    先测通用节点

    先确认基础连接，再测试需要 IPv6 的流量节点。

  • 04
    转到网络排障

    仍然失败时查看网络异常排查，一次只改一个变量。
